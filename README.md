
# PetShop - TCC 🐾️

Sistema de gerenciamento para PetShop desenvolvido como projeto de conclusão de curso (TCC) em Desenvolvimento de Sistemas

## 🚀️ Status do Projeto
Em desenvolvimento ⚒️

## 👨‍💻️ Tecnologias Utilizadas
* **Java 21**: Linguagem principal.
* **Spring Boot**: Framework para criação da API REST.
* **PostgreSQL**: Banco de dados relacional.

## ⚙️ Como Executar o Projeto
1. Clone o repositório:
   ```bash
   git clone https://github.com/gusttavodeodato/pet-shop-tcc-etec.git
   ```
2. Configure o banco de dados PostgreSQL no arquivo:
    ```bash 
    src/main/resources/application.properties
    ```
3. Execute o projeto através da sua IDE(IntelliJ) ou via terminal:
    ```bash
    ./mvnw spring-boot:run
    ```
